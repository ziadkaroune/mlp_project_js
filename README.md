# MLP42

MLP42 is a machine learning project currently under development. The project is being built incrementally, with the data preparation and application structure implemented first.

## Current Progress

The project currently includes:

- Project entry point and initial application structure
- Loading data from `data.csv`
- Data filtering and preparation logic
- Initial JavaScript implementation in `index.js`
- Supporting data-processing logic in `dataFilter.js`

## Development Status

This repository represents an active development version of the project. The core data-handling foundation is in place, but the complete machine learning workflow is still being developed.

The model training phase has not been integrated yet and will be added in a future update. Until then, the project should be considered an early working version rather than a final release.

## Planned Work

- Implement the training pipeline
- Connect prepared data to the model
- Add evaluation and accuracy metrics
- Improve error handling and validation
- Add usage examples and tests
- Document the final workflow
